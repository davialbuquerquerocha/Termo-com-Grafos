SOLVER DE ENTROPIA - GUIA RAPIDO
================================

Este pacote oferece dois modos de escolha de palpite:

- entropy: calcula a entropia dos palpites e escolhe o mais informativo.
- groups: avalia recursivamente os grupos de feedback para minimizar o custo
  esperado. deep e um alias mantido para compatibilidade.

Quando restam uma ou duas respostas candidatas, entropy escolhe a primeira
candidata da lista, como groups, em vez de usar o desempate geral por entropia.

Todos os comandos abaixo devem ser executados na raiz do projeto:

    cd "C:\Users\arthu\OneDrive\Desktop\Termo\Termo-com-Grafos"

JOGAR INTERATIVAMENTE
---------------------

Entropia comum:

    python -c "from algorithm.entropy.algorithm import main; main()" play --strategy entropy
    python -c "from algorithm.entropy.algorithm import main; main()" play --strategy entropy --answer-list solutions

Busca recursiva dos grupos:

    python -c "from algorithm.entropy.algorithm import main; main()" play --strategy groups
    python -c "from algorithm.entropy.algorithm import main; main()" play --strategy groups --answer-list solutions
    python -c "from algorithm.entropy.algorithm import main; main()" play --strategy groups --max-k 100

SIMULAR UMA RESPOSTA
--------------------

    python -c "from algorithm.entropy.algorithm import main; main()" simulate TERMO --strategy entropy
    python -c "from algorithm.entropy.algorithm import main; main()" simulate TERMO --strategy groups
    python -c "from algorithm.entropy.algorithm import main; main()" simulate TERMO --strategy groups --answer-list solutions

AVALIAR RESPOSTAS
-----------------

Avaliacao completa das respostas possiveis (pode demorar). Por padrao,
usa termo_palavras_aceitas.txt; --answer-list solutions seleciona
termo_solucoes_possiveis.txt:

    python -c "from algorithm.entropy.algorithm import main; main()" evaluate --strategy entropy --answer-list accepted
    python -c "from algorithm.entropy.algorithm import main; main()" evaluate --strategy groups --answer-list solutions
    python -c "from algorithm.entropy.algorithm import main; main()" evaluate --strategy groups --answer-list solutions --max-k 100

A avaliacao pode usar varios processos da CPU. O padrao e um worker (execucao
serial); escolha a quantidade com --workers:

    python -c "from algorithm.entropy.algorithm import main; main()" evaluate --strategy entropy --workers 4
      

O paralelismo distribui as respostas avaliadas entre processos. Na busca do
primeiro palpite de groups, os grupos de feedback desse palpite sao distribuidos
entre os workers; em seguida, os outros palpites candidatos tambem sao avaliados
em paralelo. Nao ha pools aninhados: a recursao dentro de cada grupo continua
serial. O desempenho depende da CPU e do tamanho da amostra. Cada worker usa seu proprio
arquivo entropy_memo_worker_*.sqlite3 para evitar concorrencia de escrita; os
resultados por resposta continuam no banco principal e podem ser retomados
normalmente. Se duas execucoes usarem o mesmo banco ao mesmo tempo, as gravacoes
aguardam a liberacao do SQLite por ate cinco minutos; ainda assim, evite iniciar
avaliacoes simultaneas com a mesma lista.
Durante a busca inicial, o programa mostra a palavra base que esta sendo
avaliada e informa a cada 10.000.000 grupos de feedback recursivos concluidos.
Tambem identifica cada palpite concluido na etapa paralela.
No modo groups, a busca descarta estrategias que nao consigam resolver todos os
ramos em ate seis tentativas; entre as estrategias viaveis, minimiza o custo
esperado. Em estados grandes, a lista de palpites examinados e limitada pela
classificacao de entropia: se nenhuma estrategia viavel for encontrada, isso
pode significar que os palpites considerados nao bastaram, nao que seja
impossivel resolver em seis usando qualquer palavra do vocabulario.

Teste uma amostra deterministica antes da avaliacao completa. A amostra limita
as respostas da lista selecionada; o solver continua usando toda a lista aceita
como vocabulario de palpites:

    python -c "from algorithm.entropy.algorithm import main; main()" evaluate --strategy entropy --sample-size 2000 --seed 2026 --profile
    python -c "from algorithm.entropy.algorithm import main; main()" evaluate --strategy groups --sample-size 200 --seed 2026 --profile

Opcoes de avaliacao:

- --sample-size N: avalia N respostas sorteadas da lista selecionada.
- --answer-list accepted|solutions: escolhe as respostas possiveis entre
  termo_palavras_aceitas.txt (padrao) e termo_solucoes_possiveis.txt. O
  vocabulario de palpites continua sendo termo_palavras_aceitas.txt. Acentos
  sao ignorados na comparacao de feedback, mas a grafia original e preservada
  nos resultados.
- --seed N: define a semente da amostra; o padrao e 2026.
- --checkpoint-interval N: grava resultados a cada N respostas; o padrao e 100.
- --workers N: numero maximo de processos para busca groups e avaliacao; o padrao e 1.
- --max-k N: limita a quantidade maxima de palpites candidatos avaliados em
  cada estado da busca groups. Deve ser maior que zero; sem a opcao, o solver
  mantem a selecao automatica atual. Um limite menor pode acelerar a busca,
  mas tambem pode excluir o palpite que levaria a melhor solucao. Quando
  --max-k e menor que MIN_K, o limite maximo prevalece; por exemplo, com
  MIN_K=5 e --max-k 1, o minimo efetivo registrado nos resultados e 1.
- --profile: mostra tempos e contagens de operacoes da busca.
- --no-resume: ignora resultados salvos para a selecao atual e recalcula a
  amostra selecionada.

RETOMADA E ARQUIVOS
-------------------

- dataset\cache\entropy\entropy_memo.sqlite3 guarda estados resolvidos da busca groups e os
  resultados de avaliacao por resposta. Execucoes seguintes reutilizam esses
  dados quando a lista, a estrategia e a configuracao forem compativeis.
- dataset\results\entropy_games_<estrategia>_<AAAAMMDD_HHMMSS>.json guarda os
  resultados individuais: resposta, numero de tentativas e cada palpite com o
  feedback obtido para aquela resposta. As sequencias sao simuladas
  independentemente por resposta, nao inferidas de jogos parecidos, e
  atualizadas a cada checkpoint. Ao concluir, o JSON inclui tambem as metricas
  agregadas. Uma execucao interrompida deixa o JSON marcado como incompleto;
  jogos antigos sem sequencia sao simulados novamente ao retomar. Avaliacoes
  compativeis reutilizam o arquivo existente para preservar a retomada.
- dataset\cache\entropy\entropy_first_guess_<lista>.json guarda o primeiro palpite calculado
  para a busca groups e e separado conforme a lista de respostas selecionada.
- dataset\cache\entropy\entropy_runtime.log recebe eventos JSONL das avaliacoes, incluindo
  inicio, configuracao, etapas, lotes concluidos e checkpoints. O arquivo e
  sempre aberto em modo append; registros existentes nao sao substituidos.
  Durante a avaliacao paralela, uma linha de heartbeat e acrescentada a cada
  30 segundos sem conclusao de lote; os workers tambem registram o inicio e a
  conclusao de cada resposta e imprimem esse progresso no terminal.
- dataset\cache\feedback-matrices\feedback_matrix_*.npy guarda a matriz de feedback pre-calculada.

Os arquivos SQLite e seus auxiliares sao ignorados pelo Git. Nao apague o banco
se quiser retomar uma execucao interrompida. Para recalcular resultados de uma
amostra, use --no-resume.

IMPORTACAO EM PYTHON
--------------------

    from algorithm.entropy import evaluate_solver, interactive_play

    interactive_play(strategy="entropy")
    result = evaluate_solver("groups")
    print(result.average_attempts)

strategy aceita "entropy", "groups" ou "deep". A avaliacao completa nao e
executada automaticamente ao importar o pacote.
